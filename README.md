# valentinratigniet-byte.github.io

Source du site vitrine du portfolio, servi par GitHub Pages :
**https://valentinratigniet-byte.github.io/**

Une seule page (`index.html`), HTML/CSS/JS vanilla — même discipline "zéro
dépendance" que [projet-14-filiation](https://github.com/valentinratigniet-byte/projet-14-filiation).
Aucune donnée fabriquée : les 19 projets listés reprennent tels quels les
chiffres déjà publiés dans le
[README de profil](https://github.com/valentinratigniet-byte/valentinratigniet-byte)
et dans le README de chaque dépôt.

Identité visuelle **Petrol & Ambre**, charte définie dans
[`portfolio-data/brand/palette.md`](https://github.com/valentinratigniet-byte)
(dépôt local, non publié séparément).

## Mettre à jour

Le contenu des projets est un tableau JS (`PROJECTS`) directement dans
`index.html` — pas de build, pas de génération. Ajouter/modifier un projet :
éditer ce tableau, commit, push sur `main`. GitHub Pages republie
automatiquement.
